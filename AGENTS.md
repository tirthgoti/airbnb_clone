# Project Agent Instructions

## Project
This is a React + TypeScript + Vite front-end clone of an Airbnb property listing.

## Working conventions
- Keep the reference listing as the visual source of truth.
- Preserve responsive behavior for desktop and mobile layouts.
- Use existing React, TypeScript, Vite, Lucide React, and CSS patterns before adding dependencies.
- Keep listing content and imagery local to the project.
- Run `npm run lint` and `npm run build` after implementation changes.
- Do not commit `node_modules`, generated secrets, or environment files containing credentials.

## Scope
The current project is a static front-end prototype using mock listing data. Backend booking, authentication, and payments are outside the assignment scope.
