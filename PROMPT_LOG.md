# AI Prompt History

This file is a submission-friendly record of the AI prompts used during the assignment. The work was completed iteratively against the provided Airbnb listing reference and saved HTML reference.

## Initial implementation

- Make an Airbnb clone.
- Help me develop the clone module by module.
- Match the presentation against the reference and identify differences and bugs.
- I want it to look the same as the reference.

## Reference matching

- I am giving you the HTML file of what I want. Use this as the reference and make the clone match it.
- Match the presentation in the HTML, including guest favourite, about section, calendar selection, and related listing details.
- Use the saved HTML as the canonical source of truth for copy, layout, assets, and styling.
- Replace inconsistent icon glyphs with a consistent icon library.
- Extract and use the reference Airbnb logo and font where appropriate.

## Finalization and submission

- Move to the final submission phase after the UI fidelity pass.
- Create the submission documentation and finalize the project packaging.
- Start implementation of the final delivery requirements.
- Make sure the architecture and prompt files are ready.
- Check whether everything is up to date before submission.
- Prepare the project as one zip without `node_modules`, include AI configuration files, include an architecture diagram, and provide instructions for deploying and sharing the live app.

## Verification prompts

- Run lint and production build checks.
- Confirm the browser page renders and the main listing sections are present.
- Verify the final repository contents before creating the submission archive.

## Scope note

The final app is a front-end clone with static mock data. It does not implement a real backend booking, authentication, payment, or database workflow.
